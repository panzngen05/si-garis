Kebijakan Privasi — Si Garis Uploader

Terakhir diperbarui: 21 November 2026

Si Garis Uploader adalah alat pribadi yang mengunggah video ke kanal YouTube milik pengguna sendiri (kanal "Si Garis") melalui YouTube Data API v3.

Data yang diakses

Aplikasi ini hanya mengakses kanal YouTube milik pengguna sendiri, dengan izin (scope) youtube.upload. Izin ini dipakai untuk mengunggah video serta mengatur judul, deskripsi, dan visibilitas video tersebut. Aplikasi ini tidak mengakses, membaca, atau mengubah data kanal lain.

Data yang disimpan

Token akses OAuth (access token dan refresh token) disimpan di server milik pengguna sendiri, semata-mata agar proses unggah dapat berjalan otomatis. Token tersebut tidak dibagikan kepada pihak mana pun.

Data pihak lain

Aplikasi ini tidak mengumpulkan, menyimpan, atau membagikan data pribadi orang lain.

Pihak ketiga

Data video hanya dikirim ke Google/YouTube melalui YouTube Data API resmi, untuk keperluan publikasi video ke kanal pengguna.
